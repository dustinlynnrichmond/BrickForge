# BrickForge

BrickForge is a construction-brick-inspired Android customization project. **This is a clean rebuild.** It does not import the legacy monogram generator or the old ZIP-based Android project.

## Product goal
Give each installed app a recognizable, individually crafted 3D brick-style icon with realistic studs, seams, plastic material, highlights and shadows. Let users personalize supported icon packs, wallpapers, widgets, and keyboard surfaces.

## Repository layout
- `docs/PRODUCT_SPEC.md` — feature and visual requirements, platform limits
- `docs/IMPLEMENTATION_PLAN.md` — architecture, milestones, tests and release checklist
- `.github/workflows/android.yml` — Android CI build (activates when Android source is added)

## Important
The repository currently contains planning and CI scaffolding, **not an installable Android app**. Do not publish a release or promise a working APK until an Android Studio project, original icon assets, mapping metadata, and Samsung device tests are complete.

## Branding
Use **BrickForge** in the product, package assets and documentation. Do not use third-party toy trademarks or imply their endorsement. Respect third-party app icon rights.
